About TestersHub

Independent QA for web applications, mobile apps and APIs, from Mumbai to clients worldwide.

TestersHub is an independent software testing service based in Mumbai, India, founded by Gaurav Prasad, a QA automation engineer.

We help startups and product teams find the bugs before their users do, across web applications, mobile apps and APIs. When you work with TestersHub, you work directly with the engineer testing your product: no account managers and no hand-offs.

What we do

  • Web application testing: functional, cross-browser, regression and accessibility
  • Mobile app testing on real Android and iOS devices
  • API testing: functional, security basics and load
  • Test automation with Playwright, Appium, Postman and REST Assured, wired into your CI/CD pipeline

How we work

  • A fixed quote before any work starts
  • Your NDA signed before we see your product
  • Bugs logged in your own tracker, with clear steps and evidence
  • Every fix retested for free
  • Every automated test we write lives in your repository

Our own site is tested too

This website is checked on every release with Playwright, axe accessibility scans, Lighthouse and Postman, running in a GitHub Actions pipeline. It's the same approach we bring to client projects.
