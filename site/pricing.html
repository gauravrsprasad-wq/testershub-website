How test packs work

  • Each pack covers 20 test cases for $10.
  • Need more? Add more packs. The number of packs is rounded up, so 25 test cases need 2 packs.
  • We send you the list of test cases and the number of packs needed. You approve both before any work starts.

Example: testing sign-up and checkout with 45 test cases needs 3 packs: 3 × $10 = $30.

What counts as a test case?

One test case is one scenario checked from start to finish, for example "a user can apply a promo code at checkout". Every test case includes:

  • Writing the test case, with clear steps and the expected result
  • Running it on the agreed browsers, devices or API environment
  • Logging any bugs found, with steps to reproduce and evidence
  • A free retest after your team fixes a bug
