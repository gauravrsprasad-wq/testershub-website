What a test looks like

Tests read like the user journey they check. This is an example in Playwright with TypeScript:

Example: checkout.spec.ts (Playwright)

import { test, expect } from '../fixtures';

test('a customer can apply a promo code at checkout', async ({ cartPage, checkoutPage }) => {
  await cartPage.open();
  await cartPage.addProduct('Wireless Headphones');   // ₹1,999
  await checkoutPage.applyPromo('SAVE20');             // 20% off

  await expect(checkoutPage.discount).toHaveText('-₹399.80');
  await expect(checkoutPage.total).toHaveText('₹1,599.20');
});
